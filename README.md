# Chérie Lou newsletter popup — artwork

Image assets for the cherielou.com newsletter popup, served via jsDelivr.
Design by rawpetal studio.

## Versions

- `v2` — original popup artwork and button assets
- `v3` — alt.3 envelope, letter card, headline, and body copy
- `v4` — alt.4 artwork with the updated Chérie Lou body-copy lettering
- `v5` — final envelope and two approved lettering-size options
- `v6` — client-selected Option 02 with the original flower-free envelope texture
- `v7` — supplied envelope-front cleanup layer and corrected Option 02 body lettering

The `v5` shared artwork uses `envelope-back.webp`, `envelope-front.webp`,
`letter-card.webp`, and the Submit/Close files. Choose
`headline-small.webp` + `letter-text-small.webp` for the larger-title
version, or `headline-large.webp` + `letter-text-large.webp` for the
larger-body-text version.

The `v6` artwork restores the original flower-free `envelope-back.webp`,
`envelope-front.webp`, and `letter-card.webp`. The corrected Option 02 body
copy is rendered as live HTML text in the delivered popup files.

Web pages should use the tagged jsDelivr URLs so published artwork does not
change when newer versions are added.
