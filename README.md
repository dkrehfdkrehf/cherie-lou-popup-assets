# Chérie Lou newsletter popup — artwork

Image assets for the cherielou.com newsletter popup, served via jsDelivr.
Design by rawpetal studio.

## Versions

- `v2` — original popup artwork and button assets
- `v3` — alt.3 envelope, letter card, headline, and body copy

Web pages should use the tagged jsDelivr URLs so published artwork does not
change when newer versions are added.
